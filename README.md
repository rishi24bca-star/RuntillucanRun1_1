# RuntillucanRun – Zombie Survival Game 🧟

RuntillucanRun is a 3D zombie survival game I'm developing in Unity using C#.

This is a personal learning project that I'm building to get more hands-on experience with game development. I'm working on different gameplay mechanics, enemy AI, animations, combat systems and other Unity features while developing the game.

The project is still in progress, and I'm regularly adding new features and improving existing ones.

## About the Game

The basic idea is simple: survive against zombies, fight them and try to stay alive.

I'm currently focusing on player controls, shooting mechanics, zombie behaviour and making the different gameplay systems work together.

## Current Features

### Player
- Player movement and directional controls.
- Mouse-based aiming.
- Shooting and attack mechanics.
- Raycasting for aiming and shooting direction.
- Player animation handling.

### Zombies
- Zombie movement using NavMesh Agent.
- Enemy detection and player tracking.
- Zombie attack and damage mechanics.
- Dynamic zombie spawning around the player.
- Spawn distance and radius control.
- Limiting the number of active zombies.

### Animations & Effects
- Player and zombie animations.
- Idle, walking and attack states.
- Event-based animation handling.
- Audio integration.
- Particle effects and combat VFX.

### Other Implementations
- Collision detection and attack range systems.
- Communication between scripts using events.
- Separating gameplay logic into different scripts to reduce dependencies.
